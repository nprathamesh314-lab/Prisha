# PRISHA XPRESS PVT. LTD.
## OLD-TO-NEW CONTENT MAPPING MATRIX

> **Purpose:** Detailed comparative audit demonstrating how content, architecture, positioning, and data from the legacy website (`https://www.prishaxpress.com/`) were systematically elevated into the new modern enterprise logistics platform.  
> **Guiding Principle:** Preserve actual corporate identity and verified facts without inventing unsupported claims, while dramatically upgrading structure, vocabulary, UI/UX, and data governance.

## 4. Careers & Recruitment: Architectural Transformation

| Feature | Legacy Approach | Enhanced Modern Architecture |
| :--- | :--- | :--- |
| **Application Intake** | Generic "Send Message" email box for all queries. | **Two Independent Modules:**<br>&bull; **Module A (Staff):** `/careers/staff-application` (Resume upload, departmental selection, corporate HR)<br>&bull; **Module B (Driver):** `/careers/driver-registration` (License verification, vehicle class, Aadhaar/PAN, experience) |
| **Database Architecture** | No database (untracked emails). | **Strictly Segregated Supabase Schemas:**<br>&bull; `staff_applications` table (HR permissions only)<br>&bull; `driver_applications` table (Driver Admin & Verification Team only)<br>&bull; Separate document storage buckets and audit trail tables. |
| **Verification Bay** | None. | Dedicated `/admin/driver-verification` interface with interactive document inspection, license checks, road-test logging, and single-click approval. |
| **Approved Driver Master** | None. | Dedicated `/admin/approved-drivers` TMS-ready master registry with driver search, export capabilities, and status badges. |
